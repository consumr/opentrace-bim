OpenTrace BIM v0.42.2 — Alpha
INSTALLATION / INSTALLAÇÃO — MANUAL ONLY

ENGLISH
1. Close IngeTrazo and back up the original OpenTrace_BIM plugin folder outside the scanned plugins folder.
2. In IngeTrazo choose Extensions > Open plugins folder and note the path; close the host.
3. Extract this ZIP and replace the entire OpenTrace_BIM folder (do not mix different builds).
4. Ensure .../ingetrazo/plugins/OpenTrace_BIM/__init__.py exists directly inside that folder.
5. Restart IngeTrazo and use a disposable .igz for first tests.

PORTUGUÊS
1. Feche o IngeTrazo e salve um backup fora da pasta plugins.
2. Localize Extensions > Open plugins folder e depois feche o programa.
3. Extraia o ZIP e substitua a pasta OpenTrace_BIM inteira, sem mesclar arquivos avulsos.
4. Confirme .../ingetrazo/plugins/OpenTrace_BIM/__init__.py (sem duas pastas aninhadas).
5. Reinicie e valide primeiro em um arquivo .igz descartável.

FRANÇAIS
Fermez IngeTrazo et sauvegardez l'ancien dossier hors de plugins. Ouvrez Extensions > Open plugins folder, remplacez le dossier OpenTrace_BIM complet et redémarrez. Vérifiez OpenTrace_BIM/__init__.py sans double imbrication. Testez sur un document de test.

ESPAÑOL
Cierre IngeTrazo y guarde una copia de seguridad fuera de plugins. Abra Extensions > Open plugins folder, reemplace toda la carpeta OpenTrace_BIM y reinicie. Compruebe OpenTrace_BIM/__init__.py sin carpetas duplicadas. Pruebe con un documento de prueba.

DEUTSCH
Schließen Sie IngeTrazo und sichern Sie den bisherigen Ordner außerhalb von plugins. Öffnen Sie Extensions > Open plugins folder, ersetzen Sie den gesamten Ordner OpenTrace_BIM und starten Sie neu. Prüfen Sie OpenTrace_BIM/__init__.py ohne doppelte Ordner. Zuerst mit einer Testdatei prüfen.

No automatic .bat/.py installer is bundled in this Alpha release. Old documentation inside archived handoff files is historical and may describe superseded behaviors.
