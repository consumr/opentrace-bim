# OpenTrace BIM — isolated experiment: wall-edge surface finishes / isometric UV preview

**NONOFFICIAL / ISOLATED TEST PACKAGE.** Do not publish, merge, modify another repository, or update official records without the owner's express authorization. Built from `OpenTrace_BIM-EXPERIMENTAL-ISOLADO-BIBLIOTECAS-PAREDES-PREVIAS.zip`; prior ZIP stays intact.

## What changed

- **Wall → Material → Edge finishes (surface paint only):** four independently selectable native materials: **Start end**, **Finish end**, **Wall top**, **Wall bottom**. The first option, `Use layer material`, removes the explicit override and restores the composition/material native to that face. Material choices use the same searchable, categorized material picker already used for parametric surfaces.
- **Geometry not changed:** the feature paints existing parametric faces (`ap_wall_side` semantic labels `start/end/top/bottom`). It does **not** generate thin wall elements, add physical thickness, change junction priorities, paint opening reveals or alter host geometry.
- **Persistence:** the optional `edge_materials` map is saved in the wall's existing parametric `.igz` metadata; older walls without that key remain valid. A wall edited through the parametric controller continues to carry the choices. Creation of straight/rectangular walls and junction remeshing also respects the settings. The document material registry keeps normal native IngeTrazo material definitions.
- **Undo / Redo:** a dedicated `PaintWallEdgeFinishes` history command updates face material attributes without rebuilding the mesh; editing other wall parameters remains on existing parametric history operations. Cosmetic finish changes do not invalidate the heavy wall-junction geometry cache.
- **Isometric library preview:** fixes skewed brick/tile courses by affinely projecting the bitmap onto the tilted front-face parallelogram. This is only a drawing change in `wall_visuals.py`; no host texture coordinates, UVW mapping or renderer settings were changed.

## Windows acceptance steps

1. Create a **simple** wall and select it; find `Edge finishes · surface paint only`. Choose different materials for Start end, Finish end and Wall top. Check that no new object appears and wall dimensions remain the same.
2. Repeat with a **composite** (clay block plus plaster or tile) wall. The selected end should show one chosen material across its physical layers, while faces and openings retain their normal materials.
3. Switch one finish back to `Use layer material` and verify the original end's physical layers reappear. Test Undo/Redo and Save/Reopen `.igz`.
4. Change wall height or thickness, then test a wall junction to ensure the finish follows the regenerated faces without distorting the mesh.
5. In the library inspect the isometric preview of **Structural concrete block 19 cm** and **Clay block 14 + tile on both sides**: courses should follow the angled face. Compare with the real viewport; only the preview changed.

## Important limits

- This is a **surface coat representation only**; no waterproofing, capping roof tile, flashing or thermal/physical wall buildup is generated by it.
- Edges created by **wall-hosted openings** (`opening`) and exposed long side surfaces (`side`) are deliberately not affected.
- Existing special manual painting may require visual inspection when a new override replaces paint on those exact edge faces. Clearing an override restores the standard layer material, not an arbitrary older custom paint, except through Undo.
- No changes made to any GitHub branch, repository, official caderno or IngeTrazo source files. No automatic updater enabled.
